# WhaleBar UX 设计描述

> 版本：v0.3 · 更新日期：2026-09-18 · 设计原则：**一眼可得、不打扰、降级优雅**
> v0.3 变更：移除用量卡与趋势图（功能整体下线）；余额卡改为深海军蓝低饱和渐变（缓解晃眼）；字号继续上调（正文 callout/footnote 起步，金额 34pt 圆体）。

## 1. 菜单栏（Status Bar）

常驻菜单栏，无 Dock 图标、无主窗口。

```
正常：    🐋 ¥86.20
仅数字：  ¥86.20          （设置中可切换显示样式）
仅图标：  🐋
未配置：  🐋 开始使用      （点击直达引导）
```

- 默认样式：鲸鱼图标 + 总余额（优先 CNY；多币种取余额最大者）。
- 点击即弹出/收起面板（MenuBarExtra window 样式，非下拉菜单）。
- 请求失败时 **保持最后一次数值**，不闪烁、不清空，错误只在面板内呈现——状态栏保持「安静」。
- 设置中修改样式/刷新间隔 **立即生效**（@Observable 存储属性驱动，无需重启）。

## 2. 下拉面板（280pt 宽）

线框示意：

```
┌──────────────────────────────┐
│ ⚠ API Key 无效          [⚙]  │  ← 错误横幅（仅运行期错误，凭据类附跳转）
├──────────────────────────────┤
│ ╭──────────────────────────╮ │
│ │🐋 DeepSeek 余额   (● 可用)│ │  ← 深海军蓝低饱和渐变主卡
│ │                            │ │     （#212C4F → #14243E，
│ │ ¥ 86.20       (34pt 圆体)  │ │      白色文字，柔和不晃眼）
│ │ 赠送 ¥10.00 · 充值 ¥76.20  │ │     callout 白色小字
│ │ 其他：$ 5.00               │ │     多币种时展示
│ │ 最后更新 14:32        (⟳)  │ │     白色圆形刷新钮
│ ╰──────────────────────────╯ │
│                              │
│ [⚙设置]      [↗控制台] [⏻退出]│  ← 底栏（body 字号）
└──────────────────────────────┘
```

### 视觉风格

- **余额卡（唯一主视觉）**：深海军蓝双色渐变圆角卡（14pt 圆角，色值 `RGB(0.13,0.24,0.40) → RGB(0.08,0.16,0.29)`），低饱和、深底白字，久看不晃眼；白色 34pt 圆体大字总额；右上「可用/余额不足」白色半透明胶囊 + 状态色圆点；白色圆形刷新按钮（刷新中转圈）。
- **字号策略**：正文以 callout（12pt）/ footnote（11pt）起步，金额 34pt，底栏 body（13pt）；仅「其他币种/最后更新」等辅助信息用 footnote。
- **错误横幅**：红/橙浅底圆角条，callout 字号，API Key 类错误附齿轮跳转设置。
- **空态/引导**：未配置凭据时余额卡内直接展示引导文案 + 白底「去配置」按钮。

## 3. 设置窗口

从面板底栏「⚙」或右键菜单打开（`Settings` scene，⌘, 亦可用）。分区从上到下：

1. **凭据**
   - `DeepSeek API Key`（SecureField）+ 「验证并保存」按钮 → 立即调一次余额接口验证，成功/失败即时反馈。
   - 已保存状态用「当前：已配置」+ 「移除」按钮表达，不回显明文。
2. **刷新**：间隔选择（1/5/15/30 分钟）+ 上次更新时间。
3. **状态栏显示**：样式（图标+数字 / 仅数字 / 仅图标）。
4. **关于**：版本号、数据来源（DeepSeek 官方 API）、凭据存储（macOS Keychain）。

所有设置修改即时生效。

## 4. 首次启动引导

- 无凭据时，首启自动打开引导窗口（设置窗口 + 顶部两步说明：① 获取 API Key → ② 粘贴验证）。
- 引导完成后菜单栏从「🐋 开始使用」切换为真实数值。
- 关闭引导窗口不弹二次打扰；状态栏保持入口提示直到配置完成。

## 5. 状态与反馈汇总

| 场景 | 状态栏 | 面板 |
|------|--------|------|
| 正常 | 🐋 + 数值 | 横幅隐藏，数据实时 |
| 刷新中 | 数值不变，刷新按钮转圈 | 无侵入 |
| 断网/超时 | 保持最后数值 | 橙色横幅「网络不可用，显示缓存数据」 |
| API Key 无效 | 保持最后数值 | 红色横幅「API Key 无效」+ [去设置] |
| 余额不足 | 数值正常 | 可用胶囊红点提示 |
